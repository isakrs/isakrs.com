# Temperature signal story

Five separate illustrations for `/data-platform/`:

1. `01-signal.jpg`: sensor A produces timestamped readings.
2. `02-shared-data.jpg`: readings join a checked, governed dataset.
3. `03-discovery.jpg`: exploration produces useful SQL.
4. `04-model-reuse.jpg`: later SQL models reuse earlier results.
5. `05-product.jpg`: the shared status returns to an operational product.

Created with the built-in image-generation tool on 12 November 2026. The requested direction is a sparse pen-drawn science explainer: loose charcoal lines, a red temperature signal, and one idea per drawing. These are original illustrations, not frames or traced artwork from the reference video.

The source prompts are in `generation-prompts.json`. Two refinement edits aligned the pictured values and times with the text and removed an invented numeric threshold. The teaching example does not prescribe a food-safety limit.

PNG originals were exported to 1200 × 800 JPEG at quality 88 for the site. All five images together are under 400 KB. HTML captions and alternate text carry the meaning independently of handwriting in the images.

The SQL model in the article is an illustrative extension of the public transport configuration repository. It groups by vehicle and minute; later warm-period/status models are explained conceptually, not presented as already implemented repository features.
